面向嵌入式、物联网与协议开发的本地调试工具，统一完成串口、TCP/UDP 收发、HEX/ASCII 对照、协议帧校验和实时波形分析。

## 描述

串口助手 SerialPortTool 是一款专注设备通信与协议调试的 macOS 工具。

主要功能：

• 串口端口检测，支持常用或自定义波特率、数据位、校验位、停止位和流控
• TCP/UDP 客户端与服务端模式，支持域名、IPv4、IPv6 和来源地址显示
• 文本、HEX、ASCII 与 HEX+ASCII 双栏接收视图，多编码解析与关键字过滤
• HEX、转义、换行、定时任务、快捷指令和文件分块发送
• 可配置协议帧头、帧尾、长度域、CRC16、CRC32、SUM、XOR 与校验字节序
• 实时波形解析、缩放、自动滚动和 CSV 导出
• 连接配置收藏、原始数据日志、明暗主题与常用快捷键

应用不需要注册或登录，不包含广告和分析服务。串口与协议数据默认仅在本机处理；网络数据只发送到用户明确配置的目标地址。

应用无需账号、订阅或购买。

无需硬件也可检查主要显示与解析能力：进入“收发”页，在接收区点击“⋯ 更多”→“注入模拟数据（诊断）”，可查看文本、HEX、ASCII 和双栏显示；进入“波形”页点击“载入示例”可查看曲线功能。

串口功能需要连接用户自己的 USB、蓝牙或系统串口设备。TCP/UDP 功能只连接用户明确输入的地址，或在用户选择服务端模式后监听指定端口。本地网络、串口、USB、蓝牙和用户选择文件权限均只用于这些可见功能。
